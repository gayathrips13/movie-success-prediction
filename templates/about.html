Methodology

How your project works from dataset to prediction.

1. Data Collection

Upload an IMDb/movie CSV dataset through the website.

2. Data Cleaning

Convert numeric columns, handle missing values and remove invalid rows.

3. Feature Engineering

Create log-transformed votes and gross features to reduce skew.

4. Target Creation

IMDb Rating ≥ 8.0 is labeled as movie success.

5. ML Training

Gradient Boosting Classifier learns patterns from the training data.

6. Evaluation

Accuracy, precision, recall, F1 and ROC-AUC are calculated on held-out data.

Important Academic Note

How to explain the model correctly.

This project is a supervised classification demonstration. The current target is defined from IMDb Rating, while the prediction features include year, runtime, votes and gross revenue. Because votes and gross are post-release signals, this model should be described as a movie-success assessment/prediction based on available movie performance features rather than a pure pre-release box-office forecasting model.
